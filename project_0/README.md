## Описание проекта

Угадать загаданное компьютером число за минимальное количество попыток.

:arrow_up: [к оглавлению](https://github.com/AndrewA2401/sf_data_science/blob/main/project_0/README.md#оглавление)


## Какой кейс решаем?

Нужно написать программу, которая угадывает число за минимальное количество попыток.

**Условия соревнования:**

- Компьютер загадывает целое число от 1 до 100.
- Программа должна угадать загаданное число.
- Алгоритм учитывает информацию о том, больше или меньше предполагаемое число загаданного.

**Метрика качества**

Результаты оцениваются по среднему количеству попыток при 1000 повторений.

**Что практикуем**

Учимся писать хороший код на Python, работать с функциями, циклами и условиями.

:arrow_up: [к оглавлению](https://github.com/AndrewA2401/sf_data_science/blob/main/project_0/README.md#оглавление)


## Краткая информация о данных

В проекте используются случайно сгенерированные целые числа от 1 до 100.

Для оценки эффективности алгоритма генерируется 1000 случайных чисел.

Для каждого числа определяется количество попыток, необходимых алгоритму для его угадывания.

На основании полученных результатов рассчитывается среднее количество попыток.

:arrow_up: [к оглавлению](https://github.com/AndrewA2401/sf_data_science/blob/main/project_0/README.md#оглавление)


## Этапы работы над проектом

1. Изучение условий задачи.
2. Реализация алгоритма случайного угадывания числа.
3. Разработка улучшенного алгоритма, учитывающего информацию о том, больше или меньше предполагаемое число загаданного.
4. Создание функции для оценки эффективности алгоритма.
5. Тестирование алгоритма на 1000 случайных числах.
6. Расчёт среднего количества попыток угадывания.
7. Сохранение результатов и оформление проекта на GitHub.

**Файлы проекта:**

- `game.py` — первоначальная реализация игры.
- `game_v2.py` — улучшенный алгоритм угадывания числа.
- `game.ipynb` — Jupyter Notebook с кодом проекта.
